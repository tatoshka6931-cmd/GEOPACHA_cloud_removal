# GEOPACHA_cloud_removal

This repo contains the cloud-detection component of the GeoPACHA-AI project, using an FPN with a ResNet-50 encoder to identify cloud-covered pixels in 8-band WorldView-2 satellite imagery. The main workflow is divided between cloud_removal_config.py (dataset paths, preprocessing, normalization, and model configuration), cloud_removal_training.py (model training), cloud_removal_inference.py (single-image inference and georeferenced cloud-mask generation), and batch_inference.py (batch processing). The code was developed in Vanderbilt SARL's rastervision environment and currently relies on internal data/server paths, so these will need to be updated before running it in a new environment. The accompanying GeoPACHA_documentation.docx contains the detailed methodology, engineering decisions, and final results; read this before modifying the pipeline, especially the sections on normalization, training data, and hard-negative examples, as these were important to achieving the final model performance.
